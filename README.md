# 摆谱v1.0.0测试版

### 新手小白全程使用trae编写的程序
- 哈哈哈，终于上传成功了！太不容易了😭😭😭
- 以下简介由ai代笔😎

### 家谱管理
- 支持创建和管理多个家谱
- 每个家谱可设置独特的徽章和描述
- 默认姓氏设置，简化成员添加流程

### 成员管理
- 直观的成员信息编辑界面
- 个人照片上传与管理

### 关系管理
- 智能关系推导系统
- 支持多种家庭关系：父母、子女、兄弟姐妹、配偶等
- 自动生成中文称谓，符合传统习俗

### 可视化展示
- 家谱树视图，直观展示家庭结构
- 关系图视图，展示成员间的复杂关系网络
- 成员列表视图，便于快速查找和管理

### 用户体验
- 流畅的动画和过渡效果
- 手势操作支持，如下拉返回
- 自定义底部导航栏，简化操作流程
- 适配深色模式

## 技术特性
- 使用 SwiftUI 构建的现代化界面
- 本地数据存储，保护隐私
- 高效的数据管理和缓存机制
- 模块化架构设计，便于扩展

## 注意事项
- 首次使用时，建议先创建一个家谱并添加"自己"作为参考点
- 添加成员时，可以设置与现有成员的关系，系统会自动推导其他关系
- 所有数据存储在本地，请定期备份重要信息
